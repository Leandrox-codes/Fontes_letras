# 🎵 Soundewave - Musical Instruments Store

Bem-vindo ao **Soundewave!**

O Soundewave é um projeto de site desenvolvido para apresentar uma loja de instrumentos musicais, com um visual moderno e agradável.

## 📸 Sobre o projeto

O site apresenta uma loja de instrumentos musicais, destacando diferentes equipamentos e acessórios para músicos.

## ✨ Funcionalidades

- Página inicial da loja.
- Identidade visual personalizada.
- Apresentação de instrumentos musicais.
- Botão para explorar os produtos.
- Layout moderno e organizado.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS

## 🎯 Objetivo

Praticar conhecimentos de desenvolvimento Front-end, trabalhando com estrutura HTML, estilização CSS, tipografia e organização de elementos.
